## 열기

- 비교 페이지: `index.html?theme=forest&view=lesson`
- theme: `forest`, `midnight`, `charcoal`, `matte`, `glass`, `ink`
- view: `lesson`, `practice`, `home` (파이썬 홈)
- 실제 크기로 보기: `frame.html`에 같은 query 사용
- 이미지: `academy-dark-01-forest.jpg` ~ `academy-dark-06-ink.jpg` (1~3번은 최초 3개 비교 화면, 4~6번은 전체 6개 비교 화면)

4·5번은 사용자의 모던 블랙 추가 요청, 6번은 먹물 콘셉트 추가 요청으로 제작했다. 6번 질감은 CSS 그라디언트와 장식용 도형으로 만들었으며 코드와 출력은 단색 면을 유지한다.

기존 `python-content.js`와 `PythonCourseUI`를 재사용하여 같은 레슨·문제·홈으로 비교한다. 이 시안 자체는 신규 수업이나 테마 설정을 제공하지 않는다. 실제 테마 설정은 루트의 `theme.js`, `themes.css`, `settings.css`와 `#/settings`에서 제공한다. 프레임의 읽음 버튼은 메모리에서만 동작하고 localStorage를 읽거나 쓰지 않는다. 실제 수학·파이썬 학습 기록과 운영 화면은 그대로다.

## 확인한 범위

- HTML 내부 스크립트 및 frame.js 구문 검사.
- 테마 전환 시 PC/모바일 프레임과 전체 화면 링크가 같은 theme/view를 사용함 확인.
- PC 1440px, 모바일 390px 프레임에서 실제 레슨·예제 목록·접힌 해설·파이썬 홈 확인. 모바일 문서 가로 폭과 scrollWidth가 모두 375px(스크롤바 제외).
- 비교 페이지 자체도 390px 및 320px에서 가로 넘침 없음: 각각 clientWidth/scrollWidth 375/375, 305/305. 좁은 화면에서는 모바일 미리보기만 표시.
- 각 팔레트의 paper/surface/elevated/code/output 바탕에 대한 상대 휘도 계산: 본문 최소 10.53:1, 보조 글자 최소 5.69:1, 강조 글자 최소 6.86:1. 모든 화면 상태의 포괄적인 접근성 인증을 뜻하지는 않는다.
- 추가 팔레트의 동일 계산(본문/보조/강조 최소): 매트 13.59/6.10/12.43, 글래스 14.13/6.75/7.88, 먹빛 11.05/6.23/8.73. 장식 질감과 전체 화면의 모든 조합을 계산한 결과는 아니다.
- 본문·보조 글자·코드·출력·오류·접힌 해설·읽음·버튼·hover/focus 등 기존 고정 색상을 독립 theme.css에서 덮어씀. 사이트 코드 콘솔 오류 없음(브라우저 확장 오류 제외).

## 운영 테마와의 관계

사용자 요청으로 기본 밝은 테마와 이 6개 팔레트를 전부 `#/settings`에서 선택하도록 반영했다. 운영 화면의 수학·파이썬·퀴즈·기록까지 공통 `themes.css`를 사용하고, SVG는 `visuals.js`의 CSS 변수와 기존색 fallback을 사용한다. 이 폴더의 시안은 독립적으로 보존하므로 이후 운영 테마 변경을 검토할 때 루트 파일과 실제 페이지를 기준으로 삼는다.
