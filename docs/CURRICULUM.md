# Academy 전체 교육과정 뼈대

설계 기준일: 2026-11-10 (한국 시간)

이 문서는 **대분류 → 챕터 → 레슨**의 전체 설계 인덱스다. 학습 우선순위나 구현 일정은 정하지 않는다. 아래 순서는 현재 사이트의 표시 순서이며, 각 과목 안의 챕터 순서만 이해의 흐름에 맞춘 초안이다.

## 범위 규칙

- **파이썬**: 기초까지만. 문법과 기본 자료형·제어 흐름·함수·간단한 파일/모듈·오류의 기초를 통해 작은 프로그램을 읽고 작성하는 범위.
- **파이썬 실전**: 중고급. 기초를 바탕으로 프로그램의 구조·타입·실행 특성·성능·의존성·배포·유지를 다룬다.
- **AI·머신러닝 기초 / LLM 기초**: 이름대로 기초까지만. 원리·작은 실습·평가와 한계 이해까지이며 고급 모델 연구·대규모 학습/서빙 운영으로 확장하지 않는다.
- **나머지 18개 분야**: 기초부터 해당 분야의 실무 활용까지. 실무의 상한은 과목 문서의 완료 기준으로 정한다.
- 수학은 한국 중학교·고교 교육과정을 중심으로 이어가며, 프로그래밍에 필요한 연결 선택 영역을 별도로 구분한다. 공개된 중1은 한 챕터로 보존한다.
- C++/#는 C++와 C#을 섞어 배우는 단일 언어 강좌가 아니라, 한 대분류 안의 두 독립 트랙이다. 어느 쪽도 다른 언어의 완주를 필수로 요구하지 않는다.

‘기초부터 실무’는 모든 하위 전문 분야를 망라한다는 뜻이 아니다. 스스로 작은 실제 작업을 구성하고 결과를 확인하며 문제를 진단·수정하는 능력을 목표로 한다. 난이도는 설명·판단·적용의 깊이로 높이고, 불필요하게 어려운 퍼즐로 높이지 않는다.

## 선행 관계를 읽는 방법

과목별 ‘진입 지식’과 챕터별 ‘선행’은 필요한 개념을 뜻한다. 대분류 전체를 순서대로 완주하라는 뜻이 아니다. 특정 과목의 기초 부분을 먼저 보고 돌아올 수 있다. 입문 챕터는 다른 분야의 고급 챕터를 선행 조건으로 삼지 않는다.

다른 과목의 선행 ID가 아직 특정되지 않았다면 필요한 개념을 먼저 적고 실제 집필 시 정확한 레슨을 연결한다. 모든 과목을 한 번에 구현하는 자동 작업 목록으로 사용하지 않는다.

## 설계의 기준과 구현의 기준

- 각 과목 문서가 범위·챕터·레슨 목표의 기준이다. `subjects.js`의 몇 개 예정 주제 칩은 소개용 요약이다.
- 본문 품질·예제·복습·검증의 기준은 [AUTHORING.md](AUTHORING.md)다.
- 현재 구현 상태와 시작 절차는 [START-HERE.md](START-HERE.md)를 먼저 확인한다.
- 분야 간 우선순위, 전체 학습 순서, 일정은 사용자가 나중에 정한다.
- 과목 내부 목차를 수정할 때는 기존 ID와 완료된 콘텐츠를 보존하고, 이 인덱스의 수량·경계도 함께 갱신한다.
