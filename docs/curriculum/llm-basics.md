# LLM 기초

| 항목 | 설계 |
| --- | --- |
| 과목 ID | `llm-basics` |
| 범위 | 기초 한정 |
| 목표 | 언어 모델이 텍스트를 생성하는 기본 흐름을 이해하고 입력·출력·평가·한계의 핵심 용어를 구분한다. |
| 진입 지식 | 문자열·확률의 직관·함수 입력/출력. `ai-ml-basics`의 학습/추론·특성 표현 개념을 알면 좋으나 전체 완주는 필요 없다. 코드 예시는 선택이며 고급 선형대수나 GPU 환경은 요구하지 않는다. |
| 완료 기준 | 텍스트→토큰→표현→다음 토큰 예측의 흐름을 설명하고 작은 생성 결과를 기준에 따라 비교하며 근거 확인과 정보 부족을 구분한다. |
| 콘텐츠 상태 | 설계만 완료, 본문 미작성 |

## 범위와 과목 경계

- 기초까지만 다룬다. 토큰·임베딩·문맥·어텐션의 직관, 학습과 추론의 차이, 생성 설정과 평가·한계가 중심이다.
- 실제 작업을 AI에게 나누고 코드 변경을 검수하는 협업 절차는 `ai-collaboration`, API 인증·SDK 호출·재시도 구현은 `http-api-sdk`가 소유한다.
- 검색으로 문서를 보충하는 흐름, 도구 호출, 미세조정은 용어와 역할 비교까지만 소개한다. RAG 파이프라인 구현, 벡터 DB 운영, 에이전트 프레임워크, 미세조정 실습은 포함하지 않는다.
- 설계 제안: 특정 상용 모델에 종속되지 않는 작은 토큰·확률표·문맥 도식을 사용한다. 도구를 보여 줄 때는 공식 토크나이저/모델 문서를 확인하고 무료 또는 로컬 관찰을 기본으로 하되 환경 설치를 완료 조건으로 삼지 않는다.
- 모델 사전학습, 강화학습 기반 후학습, 추론 최적화·양자화·GPU 운영, 논문 재현과 대형 서비스 배포는 제외한다.

## 챕터와 레슨

### llm-basics-ch01 · 언어 모델이 푸는 문제

- 도달점: 다음 토큰을 예측하는 원리와 대화 도구의 외형을 구분한다.

## 후속 집필 주의

- 모든 레슨에는 간단한 예제 5개, 모든 챕터에는 복습 10개를 후속 집필에서 작성한다. 현재 문서는 목표와 목차만 설계하며 수업 본문·문제·정답은 포함하지 않는다.
- 레슨별 예제 5개는 토큰·문맥·확률·생성 흐름·평가 판단에 집중한다. AI에게 질문만 반복시키는 활동을 개념 이해의 대체물로 만들지 않는다.
- 모든 모델의 토큰화·문맥 크기·지원 기능이 같다고 설명하지 않는다. 수치와 제품별 기능은 후속 집필 시점에 해당 공식 문서로 확인한다.
- 어텐션·임베딩·온도는 쉬운 도식으로 설명하되 인간의 생각·기억에 대한 비유를 실제 작동 원리처럼 단정하지 않는다.
- RAG·도구·미세조정 비교는 1개 레슨씩의 개념 소개에 한정한다. 구현 요구가 생기면 이 기초 과정에 조용히 추가하지 말고 별도 확장 범위를 결정한다.
