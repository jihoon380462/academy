# AI·머신러닝 기초

| 항목 | 설계 |
| --- | --- |
| 과목 ID | `ai-ml-basics` |
| 범위 | 기초 한정 |
| 목표 | 데이터에서 규칙을 학습하는 흐름을 이해하고 작은 지도학습 결과를 올바르게 해석한다. |
| 진입 지식 | 변수·함수·표·평균·비율의 개념. 코드 관찰에는 `python`의 함수·리스트, 표 읽기에는 `data-analysis`의 관측 단위만 필요하다. 고급 미적분·선형대수·파이썬 실전 완주는 요구하지 않는다. |
| 완료 기준 | 작은 데이터에서 학습·평가 분리를 설명하고 기준 모델과 간단한 모델의 결과를 비교하며 과적합·데이터 누출·적용 한계를 찾는다. |
| 콘텐츠 상태 | 설계만 완료, 본문 미작성 |

## 범위와 과목 경계

- 기초까지만 다룬다. 학습 데이터·특성·손실·학습/추론·일반화·평가의 개념을 중심으로 단순한 회귀·분류와 비지도학습의 역할을 살펴본다.
- 파일 정제와 탐색의 일반론은 `data-files`/`data-analysis`, 수학적 증명과 최적화 심화는 `math`, 언어 모델의 생성 원리는 `llm-basics`로 연결한다.
- 설계 제안: 작은 표와 그림으로 먼저 설명하고, 코드 관찰에는 scikit-learn의 일관된 학습·예측 인터페이스를 사용한다. 구현 시 공식 문서와 버전을 확인한다.
- 튜닝 자동화, 대형 신경망 학습, GPU/분산 환경, MLOps 배포·모니터링, 전문 분야 모델 개발, 논문 재현은 제외한다. 마지막 챕터도 입문 실험이며 실무 운영 과정이 아니다.

## 후속 집필 주의

- 모든 레슨에는 간단한 예제 5개, 모든 챕터에는 복습 10개를 후속 집필에서 작성한다. 현재 문서는 목표와 목차만 설계하며 수업 본문·문제·정답은 포함하지 않는다.
- 레슨별 예제 5개는 작은 표·예측값·오류표·단순 그래프를 사용한다. 긴 모델 코드와 수학 증명을 먼저 요구하지 않는다.
- 학습률·정규화·교차검증은 필요한 개념을 소개할 수 있으나 대규모 탐색이나 성능 경쟁을 완료 조건으로 만들지 않는다.
- 신경망은 입력·가중치·활성화·층의 직관까지이며 역전파 유도와 직접 프레임워크 구현은 제외한다.
- 알고리즘의 높은 정확도와 사실적 타당성·자료 대표성은 다른 판단임을 반복해서 확인한다.
