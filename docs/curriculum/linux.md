# 리눅스

| 항목 | 설계 |
| --- | --- |
| 과목 ID | `linux` |
| 범위 | 기초→실무 |
| 목표 | 리눅스 개발 환경과 작은 서비스 한 개를 구성하고, 상태 확인·업데이트·백업·복구를 수행한다. |
| 진입 지식 | 초반 특별한 선행 없음. 명령의 인자·경로·표준 출력·리다이렉션은 `terminal-git`의 해당 부분을 연결하며, 서비스 실습에는 작은 프로그램을 실행할 지식만 필요하다. |
| 완료 기준 | 격리된 실습 환경에서 작은 서비스를 일반 계정으로 실행하고, 로그·권한·연결을 점검하며 설정 백업과 복원 절차를 설명한다. |
| 콘텐츠 상태 | 설계만 완료, 본문 미작성 |

## 범위와 과목 경계

- 계정·파일 권한·패키지·프로세스·서비스·네트워크·저장·운영 절차를 실제 환경에서 다룬다. 단일 호스트의 작은 개발/서비스 환경 운영이 실무 상한선이다.
- `terminal-git`는 셸 문법·텍스트 처리·명령 조합·Git 이력 관리, 이 과목은 그 명령으로 다루는 시스템의 상태와 운영을 맡는다. 초반 경로 조작은 필요한 개념만 연결한다.
- `operating-systems`는 스케줄링·가상 메모리·동기화의 원리, `web`은 서비스 구현·웹 배포 맥락, `github`는 원격 협업·자동화, `data-files`는 애플리케이션 파일 형식 처리를 맡는다.
- 설계 제안: 지원 중인 Ubuntu LTS 계열의 가상머신을 기준으로 하고 구현 시 릴리스·패키지 관리자·systemd 버전을 공식 문서로 확인한다. WSL·컨테이너는 부팅·서비스·네트워크 차이를 밝히고 보조 환경으로만 다룬다.
- 대규모 클러스터, Kubernetes 운영, 배포판 제작, 커널 빌드, 기업 디렉터리 관리, 침투 테스트를 필수 범위로 넣지 않는다. 보안은 자신의 작은 환경을 보호하고 유지하는 범위다.

## 후속 집필 주의

- 실제 패키지·명령 옵션은 본문 작성 시 사용하는 배포판의 공식 문서로 확인한다. 다른 배포판의 명령이 모두 동일하다고 가정하지 않는다.
- 디스크 초기화·권한·방화벽 변경 예제는 재현 가능한 격리 환경과 복원 계획을 제시한다. 개인 주 사용 환경에서 실습하도록 전제하지 않는다.
- 명령 옵션 암기보다 현재 상태→의도한 변경→검증이라는 순서를 보여 준다. GUI가 있는 환경과 없는 환경을 구분한다.
