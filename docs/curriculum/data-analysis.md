# 데이터 분석

| 항목 | 설계 |
| --- | --- |
| 과목 ID | `data-analysis` |
| 범위 | 기초→실무 |
| 목표 | 분석 질문을 정하고 데이터를 정리·비교해, 근거와 한계를 밝힌 재현 가능한 분석 결과를 만든다. |
| 진입 지식 | `python`의 자료형·함수·반복, `data-files`의 표·자료형·CSV 읽기 개념. 평균·비율·분포와 표본 개념은 이 과목에서 필요한 만큼 보충한다. |
| 완료 기준 | 작은 표 데이터의 품질을 점검하고 재현 가능한 요약·그림·비교를 만들어 결론, 한계, 다음 확인 사항을 설명한다. |
| 콘텐츠 상태 | 설계만 완료, 본문 미작성 |

## 범위와 과목 경계

- 소유 범위는 질문→측정 기준→정제→탐색→비교→해석→보고의 분석 과정이다. 파일 형식의 세부 처리와 복구는 `data-files`, DB 내부 질의와 성능은 `sql`이 소유한다.
- 기술통계·표본·불확실성은 분석에 필요한 수준으로 보충한다. 수학적 증명과 확률분포의 전 범위는 `math`, 예측 모델 학습은 `ai-ml-basics`에 연결한다.
- 설계 제안: Python과 pandas로 표를 다루고 기본 플롯 도구로 시각화한다. 노트북과 스크립트를 비교하되 제품·라이브러리 버전은 구현 시 공식 문서로 확인한다.
- 실무 상한선은 개인 또는 작은 팀의 반복 보고와 근거 있는 데이터 비교다. 전문 통계학 전공, 인과추론 전문기법, 실시간 분산 분석, BI 제품 전체 사용법은 제외한다.

## 후속 집필 주의

- 모든 레슨에는 간단한 예제 5개, 모든 챕터에는 복습 10개를 후속 집필에서 작성한다. 현재 문서는 목표와 목차만 설계하며 수업 본문·문제·정답은 포함하지 않는다.
- 표·그림을 읽는 예제와 작은 변환 예제를 균형 있게 배치한다. 문법 암기보다 왜 그 지표나 정제 규칙을 선택했는지를 묻는다.
- 통계 레슨은 그래프와 작은 표본 변화부터 설명하고 공식의 무조건 적용을 피한다. 결측 처리·평균·p값은 전제와 해석 한계를 함께 다룬다.
- 실습 자료는 가상의 주문·이용 기록처럼 의미를 이해하기 쉬운 자료를 사용한다. 개인 식별 정보나 고위험 의사결정은 실습 완료 조건에 넣지 않는다.
- 한 번에 메모리에 올릴 수 있는 소규모 자료를 기본으로 한다. 큰 자료는 필요한 열 선택·집계·청크 처리로 연결하되 분산 도구 운영까지 확장하지 않는다.
