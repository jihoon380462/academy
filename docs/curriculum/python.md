## 범위와 과목 경계

- 기초의 끝은 문법을 조합하는 작은 단일 사용자 스크립트다. 배포 가능한 패키지, 비동기 처리, 성능 튜닝, 고급 타입 설계는 [파이썬 실전](python-practice.md)에서 다룬다.
- `input`·출력·텍스트 파일 한 개를 다루는 데 필요한 최소 I/O를 설명한다. CSV·JSON·인코딩 예외·대량 파일·스키마 검증은 [데이터 파일 다루기](data-files.md)의 주 범위다.
- 오류 메시지를 읽고 작은 원인을 찾는 기초는 여기서 다룬다. 디버거 조사, 테스트 전략·자동화는 [디버깅·테스트](debugging-testing.md), 책임 배분과 설계 원칙은 [개체지향·설계](object-design.md)에서 확장한다.
- 언어 선택은 Python 3 계열이다. 챕터 1은 기본 Python 3 코드로 작성하고 코드 샘플을 Python 3.12.14에서 검증했다. 새로운 챕터 집필 시 필요한 언어 기능과 실행 환경을 공식 문서로 확인한다. 외부 패키지 설치를 입문 첫 단계의 필수 과제로 만들지 않는다.
- 챕터 1은 레슨별 예제 5개와 복습 10개가 작성되어 있다. 나머지 챕터의 아래 목차에는 레슨 목표와 복습 평가 범위만 기록하며, 본문 집필 때 같은 문제 수를 채운다.
- 사용자가 PC에서 직접 타이핑할 수 있도록 파이썬 예제·복습은 각각 세로 목록으로 제공한다. 직접 작성·실행·수정하고 문제마다 접힌 예시 답·해설을 펼쳐 대조하는 방식이다. 후속 챕터에도 같은 사용자 요구를 유지하며 객관식 선택·퀴즈 모달·채점·점수 표시를 넣지 않는다.

## 후속 집필 주의

- 입문자의 실행 환경은 먼저 고정하되, 설치·명령줄 지식이 없는 사람을 배제하지 않는다. PC에서 코드를 직접 입력·실행하며 문제를 풀 수 있도록 레슨 2의 시작 절차를 연결한다. 모바일에서는 문제·코드·예시 답·해설을 읽을 수 있게 하며 사이트 안의 실행 기능을 전제하지 않는다.
- 레슨의 예제는 결과 예측·원인 설명·한 줄 수정·작은 조합을 섞는다. 클래스 레슨에 상속 계층·디자인 패턴·메타클래스를 끼워 넣지 않는다.
- 컴프리헨션은 읽기 쉬운 한 단계로 제한한다. 중첩 컴프리헨션·데코레이터·제너레이터·async는 실전 과정으로 연결한다.
- Python 공식 튜토리얼은 일반 프로그래밍 경험을 전제하므로 목차를 그대로 복제하지 않는다. 이 과정의 앞부분에는 값·실행·오류 읽기를 별도로 제공한다.
- 예제 5개와 챕터 복습 10개는 별도 문항이다. 기초 연결 레슨의 작은 작업이 챕터 복습을 대체하지 않는다.
