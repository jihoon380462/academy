## 범위와 과목 경계

- 기초의 끝은 문법을 조합하는 작은 단일 사용자 스크립트다. 배포 가능한 패키지, 비동기 처리, 성능 튜닝, 고급 타입 설계는 [파이썬 실전](python-practice.md)에서 다룬다.
- `input`·출력·텍스트 파일 한 개를 다루는 데 필요한 최소 I/O를 설명한다. CSV·JSON·인코딩 예외·대량 파일·스키마 검증은 [데이터 파일 다루기](data-files.md)의 주 범위다.
- 오류 메시지를 읽고 작은 원인을 찾는 기초는 여기서 다룬다. 디버거 조사, 테스트 전략·자동화는 [디버깅·테스트](debugging-testing.md), 책임 배분과 설계 원칙은 [개체지향·설계](object-design.md)에서 확장한다.
- 언어 선택은 Python 3 계열이다. 챕터 1~9는 기본 Python 3 코드로 작성하고 코드 샘플을 Python 3.12.14에서 검증했다. 수정·추가 집필 시 필요한 언어 기능과 실행 환경을 공식 문서로 확인한다. 외부 패키지 설치를 기초 과정의 필수 과제로 만들지 않는다.
- 챕터 1~9는 레슨별 예제 5개와 챕터별 복습 10개로 구성한다. 챕터 1~5·7~9는 각각 5레슨·25예제, 챕터 6은 6레슨·30예제다. 아래 목차의 46레슨과 챕터별 복습 본문을 모두 구현했다.
- 사용자가 PC에서 직접 타이핑할 수 있도록 파이썬 예제·복습은 각각 세로 목록으로 제공한다. 직접 작성·실행·수정하고 문제마다 접힌 예시 답·해설을 펼쳐 대조하는 방식이다. 후속 챕터에도 같은 사용자 요구를 유지하며 객관식 선택·퀴즈 모달·채점·점수 표시를 넣지 않는다.

## 챕터 1 점진 연습 시범 개정

현재 범위는 `python-ch01`의 5레슨(`python-l001`~`python-l005`)·25예제·10복습이다. 학습자가 PC에서 직접 적고 실행하며, 도움을 조금씩 줄여 같은 기초 동작을 다시 해보도록 구성한다. 레슨 본문에서 다루지 않은 변수·반복·함수 등을 다음 단계라는 이유만으로 요구하지 않는다. 각 레슨의 예제 5개는 다음 순서로 연결한다.

| 순서 | 연습 | 학습자가 할 일 |
| --- | --- | --- |
| 1 | 시범 따라 작성 | 짧은 시범을 직접 입력·실행하고 코드와 결과의 관계를 확인한다. |
| 2 | 일부 완성 | 주어진 틀에서 한 부분을 채우고 확인 기준과 비교한다. |
| 3 | 혼자 작성 | 완성 답 없이 요구 조건을 보고 짧게 작성한다. |
| 4 | 가리고 재현 | 앞서 확인한 시범·힌트·답을 가리고 스스로 다시 작성한다. |
| 5 | 조건 변경 | 같은 원리를 사용해 문제에 명시된 조건 한 가지를 바꾼다. |

힌트와 예시 답·해설은 각각 독립된 접힌 영역이다. 힌트만 열었을 때 완성 답이 함께 열리지 않도록 하고, 자신의 코드와 요구 결과를 비교할 확인 기준을 남긴다. 재복습 안내는 시간 간격을 두고 다시 풀 기존 레슨·예제·복습 문항을 지목한다. 새 문항을 더한 것으로 세거나 기존 읽음·최근 레슨·과거 유효 점수의 저장 키를 바꾸지 않는다.

현재 상태는 시범 개정 구현·로컬 검증 완료이며 main 병합·Pages 배포·공개 확인 전이다. 기존 Python 기초 과정의 코드 검증·공개 이력은 이번 수정 소스의 검증 결과로 재사용하지 않는다. 이번 로컬 검증에서는 Python 3.12.14의 530개 코드 블록 실행과 Chromium 156.0.8078.79 / Linux의 7그룹·48조합(8경로 × 1440/390/320px × 밝음/블랙 글래스)을 통과했다. 35문항의 단계·지시·독립 힌트/답·확인 기준, 읽음·취소·재로드·과거 점수·타 과정 기록 보존과 기존 챕터 2~9·공통 코드 표시의 호환을 확인했다. 정확한 소스·최종 표시 문구 재확인·기존 DOM 비교 범위와 단위 검사 결과는 [검증 기록](../../verification.md)에 남기며 공개 확인과 구분한다.

작업 전에 기준 SHA `2444a18bf4260c1a003183d209a3f5b2d1d6843e`를 원격 브랜치와 저장소 밖 압축 파일로 백업했다. [백업 근거와 선택 복원 안내](../backups/python-ch01-2026-11-12.md)를 따른다. 이 백업은 소스 310개 파일의 스냅샷이며 학습자 브라우저 localStorage를 포함하지 않는다. 복원은 필요한 구현 커밋의 revert를 검토하거나 별도 브랜치에서 챕터 1 원본만 선택 복원·재빌드하며 다른 챕터·공통 UI를 통째로 덮어쓰지 않는다.

파이썬 챕터 2~9와 CS 콘텐츠·기존 URL·저장 키를 유지한다. 전체 사이트 157레슨·24개 과정 키, Python 기초 9챕터·46레슨·230예제·90복습도 그대로다. 기존 콘텐츠와 학습 안내를 개선하는 PATCH 종류의 변경을 미확정 최초 목표 `0.1.0`의 같은 Unreleased에 포함하며 VERSION을 유지한다.

공식 문서의 `/3/` 주소는 이후 버전으로 갱신될 수 있다. 챕터 1이 특정 최신 버전의 전용 기능을 요구한다는 뜻은 아니며, 후속 변경 시 실제 검증한 Python 버전과 출처를 함께 갱신한다.

챕터 2 집필에서 추가로 확인한 공식 자료 (Python 3.12 문서):

- [부동소수점의 한계](https://docs.python.org/3.12/tutorial/floatingpoint.html): 일부 십진 소수의 근사 표현. 금융 처리나 고급 오차 분석은 이번 입문 범위에 추가하지 않는다.

챕터 3 집필에서 추가로 확인한 공식 자료 (Python 3.12 문서):

챕터 3에서는 `split`의 결과를 읽고 `join`에 넘기는 데 필요한 순서 있는 문자열 목록만 짧게 소개한다. 리스트 변경·반복·함수 정의는 풀이의 선행 조건으로 삼지 않으며, 컬렉션 자체의 설명은 챕터 6에서 이어간다. Python 3.12.14 코드 실행과 PC·모바일 검증의 실제 결과는 [검증 기록](../../verification.md)에 따로 남긴다.

챕터 4 집필에서 추가로 확인한 공식 자료 (Python 3.12 문서):
