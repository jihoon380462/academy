## 범위와 과목 경계

- 이 과목은 데이터 표현, 실행 계층, 네트워크·저장·분산·보안의 연결 원리를 맡는다. 실무 상한선은 작은 시스템의 선택 근거와 문제 조사 방향을 설명하는 수준이다.
- `algorithms`는 자료구조 구현·복잡도 분석, `operating-systems`는 자원관리 원리와 실측 진단, `assembly`는 명령어·호출규약을 깊게 다룬다. 여기서는 그 분야로 들어갈 공통 개념만 연결한다.
- `http-api-sdk`는 통신 규약의 사용, `sql`은 질의와 관계형 데이터 실습, `web`은 웹 구현, `linux`는 운영 명령, `debugging-testing`는 검증 절차를 맡는다. 같은 실습을 여러 과목의 필수 완주 조건으로 반복하지 않는다.
- 대학 CS 전체 학위 과정, 컴파일러 완성, 고급 계산이론 증명, 대규모 합의 알고리즘 구현은 제외한다. 과목 안의 후반 순서는 초안이며 대분류 간 우선순위를 뜻하지 않는다.

## 후속 집필 주의

- 이 과목의 자료구조·네트워크·데이터베이스 부분을 해당 대분류의 축약판으로 늘리지 않는다. 핵심 원리를 설명한 뒤 심화 과목으로 연결한다.

- 실무 종합 사례는 작은 조회/기록 서비스 한 가지로 연결하되 구현 프레임워크는 강제하지 않는다. CS2023 전체 이수와 동등하다고 표현하지 않는다.

챕터 1은 특별한 언어·운영체제·도구 설치 없이 작은 학습 메모 사례를 읽고 역할·상태·약속을 설명하는 구성이다. [콘텐츠 형식](../../content/cs/SCHEMA.md)에 따라 `python3 build-cs.py`로 `cs-content.js`를 생성하고 `python3 build-cs.py --check`로 구조와 생성물 일치를 확인한다. 묶음은 `window.CS_COURSES`, 챕터 1 별칭은 `window.CS_CH01`이며, 화면은 `cs-ui.js`에서 제공한다. 텍스트 도식은 읽기 자료이며 코드 실행·자동 채점 기능이 아니다.

분야 홈 `#/subjects/cs`와 챕터 목차·레슨·복습·내 학습을 연결하고, 읽음·최근 레슨은 `academy-cs-ch01-v1`에 따로 저장한다. 파일·복사 코드 옮기기에 포함하되 CS 키가 없는 기존 자료를 가져와도 현재 CS 원문 기록은 보존한다. 기존 수학·파이썬·알고리즘의 ID·URL·저장 키와 테마 키를 유지한다. 실제 검증 결과와 main 병합·Pages 배포·공개 확인 상태는 [검증 기록](../../verification.md)에 구분한다.
