# 데이터 파일 다루기

| 항목 | 설계 |
| --- | --- |
| 과목 ID | `data-files` |
| 범위 | 기초→실무 |
| 목표 | 파일의 구조·인코딩·자료형을 구분하고 반복 실행 가능한 작은 데이터 변환 작업을 만든다. |
| 진입 지식 | `python`의 문자열·리스트·딕셔너리·반복·함수·예외 기본 개념. 경로와 파일 개념은 이 과목에서 시작하며 다른 과목 전체 완주는 요구하지 않는다. |
| 완료 기준 | 여러 CSV/JSON 파일을 읽어 검증·변환하고 오류 기록과 출력 명세를 남기는 작업을 원본 손상 없이 다시 실행할 수 있다. |
| 콘텐츠 상태 | 설계만 완료, 본문 미작성 |

## 범위와 과목 경계

- 소유 범위는 로컬 파일의 발견·읽기·검증·변환·쓰기·재실행과 결과 인계다. 분석 질문이나 통계 결론을 만드는 과정은 `data-analysis`, 관계형 저장과 질의는 `sql`이 담당한다.
- 네트워크에서 파일을 받는 요청·인증·재시도는 `http-api-sdk`에 연결한다. 이 과목의 시작점은 이미 확보한 입력 파일이며, 네트워크 호출 자체를 깊게 가르치지 않는다.
- `python`에서는 파일 열기와 예외의 첫 경험만 다루고 여기서 형식·품질·실패 복구를 확장한다. 코드 구조와 패키지 배포는 `python-practice`, 테스트 기법의 일반론은 `debugging-testing`이 소유한다.
- 환경은 Python 표준 라이브러리 중심, XLSX에는 openpyxl 사용을 설계 제안으로 둔다. 구현 시 공식 문서와 실행 버전을 확인한다. 특정 유료 스프레드시트 앱은 필수가 아니다.
- 실무 상한선은 한 대의 컴퓨터에서 운영하는 작은 배치 변환이다. 분산 데이터 플랫폼, OCR·PDF 레이아웃 분석, 모든 바이너리 형식 역공학은 제외한다.

## 후속 집필 주의

- 모든 레슨에는 간단한 예제 5개, 모든 챕터에는 복습 10개를 후속 집필에서 작성한다. 현재 문서는 목표와 목차만 설계하며 수업 본문·문제·정답은 포함하지 않는다.
- 각 레슨에는 원리 설명 후 예제 5개를 설계한다. 경로 예측·형식 판별·짧은 변환·오류 원인·검증 선택을 섞고 실제 문제는 후속 집필에서 작성한다.
- 실습 자료는 작고 재배포 가능한 가상 데이터로 만든다. UTF-8 한글, 쉼표와 줄바꿈이 포함된 필드, 빈 파일, 중복 행을 의도적으로 포함한다.
- 스프레드시트 수식 계산과 파일 읽기를 동일시하지 않는다. 도구의 수식 지원과 저장된 계산 결과의 상태를 구현 시 확인한다.
- 파일 삭제·덮어쓰기 실습은 복사본에서 진행하도록 설계하고, 신뢰할 수 없는 직렬화 데이터를 코드 실행으로 복원하는 방식은 기본 예제로 사용하지 않는다.
