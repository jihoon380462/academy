## 범위와 과목 경계

- 일반 파이썬에서 익힌 문법을 반복해서 다시 가르치지 않는다. Python의 프로토콜·지연 계산·타입 힌트·자원 수명·동시성·배포를 실제 프로그램의 선택과 연결한다.
- [개체지향·설계](object-design.md)는 언어 독립적인 책임·의존성·변경 설계를 소유한다. 여기서는 dataclass·Protocol·모듈 경계 등 Python 표현으로 적용한다.
- [디버깅·테스트](debugging-testing.md)는 테스트 기법과 조사 방법을 소유한다. 여기서는 Python 프로젝트의 테스트 실행과 실패 재현을 통합한다.
- [데이터 파일 다루기](data-files.md)는 포맷·인코딩·스키마·파일 변환을, [HTTP·API·SDK](http-api-sdk.md)는 통신 계약·인증·재시도 정책을 소유한다. 이 과목은 그 입출력을 교체 가능한 경계로 연결한다. 네트워크가 없어도 완료할 수 있는 로컬 프로젝트를 기본으로 한다.
- **설계 제안**: Python 3의 지원되는 안정 버전, 표준 라이브러리, pyproject 기반 패키지 구성을 기준으로 한다. 구체 타입 검사기·테스트 도구·빌드 백엔드는 후속 구현 시 공식 문서와 지원 버전을 확인해 한 가지를 선택한다.
- 실무 상한은 개인/소규모 팀이 사용할 도구와 라이브러리의 구성·배포·수정이다. 프레임워크 내부 개발, C 확장, 대규모 분산 처리, 메타클래스 설계, 런타임 구현은 제외한다.
- 모든 레슨의 예제는 나중에 5개, 각 챕터의 종합 복습은 별도 10개로 작성한다.

## 후속 집필 주의

- Python의 참조·타입·실행 모델을 다른 언어의 문법과 피상적으로 대응시키지 않는다. 타입 힌트는 런타임 강제가 아니라는 점을 유지한다.
- GIL·free-threaded 빌드·프로세스 시작 방식은 버전과 플랫폼의 영향을 받는다. 특정 구현의 결과를 모든 Python 구현에 일반화하지 않고 환경을 명시한다.
- 성능 예제는 실제 측정 없이 수치를 단정하지 않는다. 비동기 예제는 외부 서비스 계정 없이 로컬 대기 작업으로 검증 가능한 구성을 우선한다.
- 기본 완료물은 로컬 설치 가능한 작은 도구다. PyPI 공개 게시, 유료 서비스 연결, 원격 배포는 이 뼈대에 포함된 자동 실행 지시가 아니다.
- 실전 과정도 한 레슨에서 여러 큰 기능을 한 번에 구현하지 않는다. 예제 5개는 해당 개념을 확인하고 챕터 복습 10개는 개념 연결을 점검한다.
