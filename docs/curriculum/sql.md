## 범위와 과목 경계

- 이 과목은 관계형 모델, SQL 질의·변경, 무결성, 트랜잭션, 기본 성능 진단과 애플리케이션 연결을 소유한다. 결과의 통계적 의미와 시각화는 `data-analysis`가 소유한다.
- 파일의 인코딩·CSV 규칙은 `data-files`, 서비스 요청과 인증 흐름은 `http-api-sdk`, 데이터베이스 내부 알고리즘의 심화는 `cs`/`algorithms`에 연결한다.
- 설계 제안: SQL의 공통 개념을 먼저 설명하고 실습 기준 DBMS는 PostgreSQL 하나로 통일한다. SQLite·다른 DBMS의 차이는 비교 주석으로 제한하며 구현 시 공식 문서 버전을 확인한다.
- 실무 상한선은 소규모 관계형 애플리케이션의 데이터 계층을 작성하고 대표 질의의 문제를 찾는 수준이다. 분산 DB, 고가용성 클러스터, 전문 DBA 튜닝과 전체 SQL 문법 사전은 제외한다.

## 후속 집필 주의

- 모든 레슨에는 간단한 예제 5개, 모든 챕터에는 복습 10개를 후속 집필에서 작성한다. 현재 문서는 목표와 목차만 설계하며 수업 본문·문제·정답은 포함하지 않는다.
- 각 레슨 예제 5개는 작은 표의 결과 예측·행 수 비교·이유 설명·질의 수정·사용 사례 선택으로 설계한다. 대규모 쿼리 암기를 요구하지 않는다.
- NULL·시간대·문자열 정렬·자동 증가·업서트 문법은 DBMS마다 다른 부분을 명확히 표시한다. SQL 공통 원리와 PostgreSQL 예제를 섞어 보편 법칙으로 설명하지 않는다.
- 실습은 재생성할 수 있는 로컬 예제 DB를 전제로 한다. 성능 레슨은 데이터 크기와 실행 환경을 기록하고 EXPLAIN ANALYZE처럼 실제 질의를 실행하는 기능의 효과를 설명한다.
- DB 내부의 B-tree 구현·스토리지 엔진·분산 합의와 전문 운영은 이 과정의 완료 조건이 아니다.
