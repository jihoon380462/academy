## 범위와 과목 경계

- 알고리즘과 기법 명칭은 영어 또는 표준 약어를 앞세워 한글을 괄호에 붙인다. `DFS(깊이 우선 탐색)`, `BFS(너비 우선 탐색)`, `DP(동적 계획법)`, `Binary Search(이진 탐색)` 등 제목과 실제 수업의 이름을 맞춘다. 약어는 본문에서 전체 영어 뜻을 소개하며 ID·실행 코드·입출력은 바꾸지 않는다. 표기 개편은 PR #21 main 병합·SHA `f732cc3`의 Pages 배포·공개 PC/모바일 확인을 완료했다. 정확한 근거는 검증 기록을 따른다.

- 레슨별 예제 5개의 1번은 핵심 개념 설명, 중요한 경우만 2번까지 설명형이며 나머지는 직접 알고리즘 함수를 작성·실행하는 문제다. 입력·반환·경계·변형 여부와 확인 사례를 문제에 제시하고, 전체 예시 코드는 접힌 풀이에 둔다. 복습 10문항의 기존 설계와 구분한다. 설명 55개·직접 구현 215개로 개편해 PR #19 main 병합·SHA `4a0beee`의 Pages 배포·공개 PC/모바일 확인을 마쳤다. 정확한 검증 범위는 검증 기록을 따른다.

- 문제 모델링, 정확성, 비용, 자료구조의 연산 특성과 작은 알고리즘 구현을 깊게 다룬다. 실무 상한은 메모리 안의 자료를 처리하는 일반 도구에서 구조를 선택하고 병목을 개선하는 수준이다.
- `python`과 `c-family`는 문법·표준 컬렉션 사용을, 이 과목은 그 구조를 선택하는 이유를 맡는다. 테스트 체계는 `debugging-testing`, 운영체제 자원 관리와 DB 인덱스의 실제 운영은 `operating-systems`·`sql`로 연결한다.
- 수학적 증명은 짧은 불변식·반례·귀납적 설명까지 사용한다. 경진대회 킬러 문제, 복잡한 균형 트리의 전체 구현, 고급 계산기하·암호 알고리즘·계산복잡도 이론의 증명은 제외한다.
- 설계 제안: 언어 중립 그림과 의사코드를 먼저 쓰고 Python을 기본 구현 예로 삼는다. 실제 집필 시 언어 버전과 표준 라이브러리 동작을 공식 문서에서 확인한다.
