# Academy — 다른 대화에서 이어서 작업하기

설계 기준일: 2026-11-10 (한국 시간)

이 문서는 새로운 대화나 새로운 작업자가 같은 의도로 이어서 만들기 위한 시작점이다. 저장소의 현재 내용을 먼저 읽고, 과거 대화의 기억만으로 구현 상태를 추측하지 않는다.

## 우리가 만드는 것

사용자가 스스로 공부하는 개념·원리 중심 학습 사이트다. 먼저 ‘무엇인가, 왜 필요한가, 왜 이렇게 되는가’를 이해하고, 작은 예제로 확인한 뒤 자기 작업에 적용하게 한다. 난도는 어려운 킬러 문제를 푸는 능력보다 설명·관찰·구현·검증 능력이 깊어지는 방향으로 올린다.

PC와 모바일에서 모두 읽고 사용할 수 있어야 한다. 기존 아이보리·포레스트 색상과 여백 중심의 교과서 디자인을 이어간다. 주제의 실무 수준이 높아져도 설명은 작은 단위로 나눈다.

교육과정 뼈대에는 미래 레슨이 많지만, 이것을 수강 가능한 레슨 수나 완료율에 포함하지 않는다. 파이썬 챕터 1 이외의 미래 목차 화면과 본문 공개는 별도 구현 범위다. 분야 소개의 예정 주제는 전체 교육과정의 완전한 목차가 아니다.

파이썬 작업의 출발점은 [과목 문서](curriculum/python.md), [콘텐츠 형식](../content/python/SCHEMA.md), `content/python/ch01/`이다. `python3 build-python.py --check-code`로 본문·풀이 예시·문항의 예시 답에 있는 Python 코드의 출력·오류를 확인하고 `python-content.js`를 생성한다. 화면과 접힌 예시 답·해설은 `python-ui.js`·`python.css`, 라우팅·읽음·최근 레슨 기록 연결은 `app.js`에 있다.

파이썬에서는 문제를 고르고 제출하는 화면을 만들지 않는다. 사용자가 PC의 편집기에서 직접 입력하고 실행한 뒤 각 문제의 예시 답·해설을 확인하는 것이 확정된 방식이다. 모바일에서도 문제·본문·해설을 읽을 수 있게 하며, 사이트 내부 코드 실행기나 자동 채점이 있다고 가정하지 않는다. 이번 문제 형식 변경은 레슨 본문이나 문항 수를 바꾸지 않는다.

파이썬 실제 경로는 `#/subjects/python`, `#/python/ch01`, `#/python/ch01/lesson/python-l001`부터 `python-l005`까지, `#/python/ch01/review`다. 챕터 2의 다음 레슨 ID는 `python-l006`이며, 사용자 요청 없이 다음 챕터를 자동 집필하지 않는다.
