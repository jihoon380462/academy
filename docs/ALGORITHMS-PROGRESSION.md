# 파이썬에서 알고리즘으로 이어지는 학습 단계 보완

기준일: 2026-11-11 KST. 사용자 요청에 따라 콘텐츠 수정 전에 검토 결과와 실행 범위를 먼저 기록한다.

## 판단 기준과 현재 상태

글·코드 길이가 아니라 동시에 유지할 상태·조건, 본문에서 문제로 옮길 때의 추론 거리, 새 상태 표현과 전략을 함께 설계하는 정도로 난이도를 판단한다. 실제 학습자 수행 측정이 아닌 콘텐츠 검토다. 파이썬 후반부와 알고리즘 기존 54레슨·270예제·90복습을 대조했다.

파이썬의 조건부 집계·작은 함수 조합은 알고리즘 첫 챕터와 자연스럽게 이어진다. 전체 난도를 일괄 낮추지 않고, 새 표현과 갱신 관계가 한꺼번에 나타나는 지점의 중간 단계를 보완한다. 본문에서 이미 가르친 관계를 한 가지 바꾸는 일반적인 응용은 유지한다. 접힌 예시 답은 문제를 풀기 전의 설명을 대신하지 않는다.

이 문서를 먼저 작성하는 시점의 구현은 54레슨이다. 아래 두 레슨을 더한 목표는 9챕터·56레슨·280예제·90복습이며 사이트 전체는 132레슨이다. 구현·로컬 검증·병합·Pages 배포·공개 화면 확인은 각각 별도로 기록한다. 계획만으로 구현 또는 공개 완료를 표시하지 않는다.

새 레슨에는 원리·작동 예시·오개념·핵심 정리와 예제 5개를 모두 작성한다. 예제 1번은 설명형, 2~5번은 직접 구현으로 구성한다. 기존 레슨의 예제도 정확히 5개로 유지한다. ch03/ch08 복습은 10개를 유지하면서 새 목표와 레슨 연결을 포함한다. 새 과제를 얹는 대신 현재 문제에 압축된 사고 단계를 분리한다.

## 식별자와 학습 순서

- 기존 l001~l054, 챕터 ID·URL·읽음/최근 레슨 저장 키는 유지한다. 표시 순서와 ID 번호는 독립적이다.
- 새 파일 `content/algorithms/ch03/lesson-07.json`은 `algorithms-l055`다. 학습 순서는 l013 → l055 → l014~l018이며 ch03의 order는 1~7이다.
- 새 파일 `content/algorithms/ch08/lesson-07.json`은 `algorithms-l056`이다. 학습 순서는 l043~l047 → l056 → l048이며 ch08의 order는 1~7이다.
- course.json의 lessonFiles와 과목 문서 표를 같은 순서로 맞춘다. 기존 파일명과 레슨 ID를 재부여하지 않는다. ID가 증가하는 순서로 자동 정렬하지 않는다.
- 19개 과정과 모든 기존 저장 키·과거 점수·테마를 보존한다. 기존 자료에서 빠진 새 레슨의 읽음을 임의로 추가하지 않는다. 새 레슨 ID가 든 자료는 해당 레슨을 지원하는 사이트에서 가져온다.

## 검증 및 버전

- MINOR 종류의 호환되는 레슨 추가와 PATCH 종류의 콘텐츠 수정을 아직 미확정인 최초 목표 `0.1.0`의 Unreleased에 포함한다. 별도 릴리스 태그는 이 작업에 포함하지 않는다.
- 구조·문항 배치·복습 분포·관련 ID, Python 작성자 코드의 정확 stdout/오류를 검사하고 algorithms-content.js를 재생성한다.
- 신규 버퍼·0/1 DP 구현을 작은 독립 기준으로 비교한다. 문제·예시 답·해설의 일치와 난이도 발판은 동료가 별도 검토한다.
- PC·모바일의 목차/앞뒤 이동·기존 URL·기본 접힌 풀이·실제 펼침·가로 넘침, 기존 및 새 읽음과 기록 파일/코드 이동을 확인한다. 수량을 132/56으로 갱신하되 검사를 완화하지 않는다.
- 변경된 콘텐츠 자산의 캐시 식별자만 갱신한다. 과목 문서·시작 문서·AGENTS·README·전체 목차·스키마를 실제 구현 상태와 함께 갱신한다. 최종 수행 결과와 소스 SHA는 verification.md에 기록한다.

현재 작업은 문서 선행 정리 후 구현·로컬 검증까지다. 이 요청에서 병합·배포·릴리스는 수행한 것으로 간주하지 않는다.
