# 교육과정 뼈대 검토 기록

검토일: 2026-11-10 (한국 시간)

## 검토 대상

22개 대분류 전체의 209개 챕터·1,100개 레슨 목차를 설계했다. 이 중 기존 공개 중1 30개를 제외한 1,070개는 미래 레슨의 제목·목표 설계다. 본문·실제 예제·복습 문항·새 UI를 구현하지 않았다. 수량은 이 설계 버전의 분할 결과이며 정해진 학습 기간이나 완주 의무가 아니다.

## 구조 확인

- `subjects.js`의 22개 분야와 문서의 파일·제목·표시 순서가 일치한다.
- 파이썬 / AI·머신러닝 기초 / LLM 기초는 기초 한정, 파이썬 실전은 중고급, 나머지 18개는 기초→실무로 표시되어 있다.
- 챕터 ID 209개, 레슨 ID 1,100개에 중복이 없고 모든 레슨 표에 제목과 목표가 있다.
- 모든 챕터에 도달점·선행 지식·복습 배분이 있으며, 209개 복습 배분의 합이 각각 실제 10이다.
- 문서 안의 명시적 챕터 참조와 상대경로 링크가 존재한다.
- 공개 중1의 기존 30개 레슨 ID와 제목이 실제 curriculum.js와 일치한다. 한 챕터·8단원 및 기존 과정/저장 키 보존 지침을 명시했다.
- 과목별 개념 경계와 선행 관계를 분담해 독립 검토했다. 대분류 전체 완주를 강제하는 순환 선행 관계는 발견하지 못했다.

## 실제 콘텐츠를 만들 때 남은 검증

이 기록은 목차와 범위의 검토다. 미래 수업의 설명 정확성, 코드 실행 결과, 문제 정답·난도, 도식·화면, 소요 시간은 본문과 구현이 작성될 때 검증한다. 공식 자료는 개념과 범위 확인에 사용했으며, 제안된 목차가 공식 인증 교육과정이나 모든 실무 영역의 완전한 목록은 아니다.

대분류 간 학습 순서와 구현 우선순위는 아직 정하지 않았다. 구체 도구·버전·운영 환경은 사용자 확정과 구분하며 실제 집필 시 다시 확인한다.
